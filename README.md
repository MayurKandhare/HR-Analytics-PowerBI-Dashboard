# HR Analytics Dashboard

An interactive Power BI dashboard designed to analyze employee attrition, demographics, salary, departments, job roles, and employee satisfaction.

## 📊 Dashboard Preview

![HR Analytics Dashboard](Screenshots/HR%20ANALYTICS%20DASHBOARD.jpg)

## 📌 Project Overview

This project uses Microsoft Power BI to analyze HR data and provide an interactive view of employee workforce patterns and attrition.

The dashboard helps analyze:

- Employee attrition
- Employee demographics
- Department-wise employee distribution
- Job roles
- Salary slabs
- Age groups
- Employee satisfaction
- Experience
- Gender distribution

## 🎯 Objectives

- Analyze overall employee attrition.
- Identify patterns in employee turnover.
- Compare attrition across departments and job roles.
- Analyze employee distribution by age, gender, and salary.
- Understand workforce characteristics.
- Create interactive KPIs and visualizations for HR decision-making.

## 📈 Key KPIs

- Total Employees
- Active Employees
- Employee Attrition
- Attrition Rate
- Average Age
- Average Experience

## 📊 Dashboard Features

### Employee Attrition Analysis

Analyzes employee attrition and identifies patterns across different workforce segments.

### Department Analysis

Compares employee distribution and attrition across different departments.

### Job Role Analysis

Analyzes employee distribution and attrition across different job roles.

### Salary Analysis

Examines employee distribution across different salary slabs.

### Demographic Analysis

Analyzes employee characteristics based on age group and gender.

### Employee Satisfaction

Provides insights into employee satisfaction and its relationship with workforce characteristics.
